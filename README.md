# Appodeal BidMachine Adapter - Swift Package

Swift Package Manager distribution of AppodealBidMachineAdapter.

## Installation

Add this repository URL to your Package.swift or Xcode project:
```
https://github.com/appodeal/Appodeal-Swift-Package-BidMachine
```

## Requirements
- iOS 15.0+
- Xcode 15.0+
- Swift 5.9+
